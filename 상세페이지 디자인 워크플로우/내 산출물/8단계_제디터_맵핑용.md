## ✅ 필수 이미지 (최소 3장 - 지금 당장 촬영 가능)

### 📷 **이미지 1: 메인 후킹컷 - "아침 시간 낭비 해결"**

**촬영 가이드:**
- **상황**: 모델이 거울 앞에서 원터치 귀걸이를 **클릭 한 번에** 착용하는 순간
- **각도**: 측면 45도 (귀 클로즈업 + 손가락이 클릭하는 모습)
- **표정**: 만족스러운 미소 (아침 시간 절약의 여유)
- **배경**: 밝은 자연광, 화이트/베이지 톤 (미니멀)

**예시:**
"왼손으로 귀걸이를 귓불에 대고, 오른손 검지로 클릭하는 순간. 딸칵 소리가 들릴 것 같은 역동적인 컷"

**목적:**
- 7단계 섹션1 "오늘 아침도 낑낑거리셨나요?" 시각화
- 7단계 섹션2 "1초의 여유" 해결책 제시
- 경쟁사 대비 차별점 "착용 편의성" 강조

**제디터 활용:**
- AI 배경 제거 → 깔끔한 화이트 배경
- 텍스트 오버레이: "클릭 한 번, 완벽한 잠금"

---

### 📷 **이미지 2: 착용컷 3장 세트 - "TPO 구분 없는 세련됨"**

#### 2-1. 오피스룩 (출근 미팅)
**촬영 가이드:**
- **의상**: 화이트 셔츠 + 블랙 재킷 (프로페셔널)
- **각도**: 측면 클로즈업 (귀걸이 + 목선 + 어깨선)
- **헤어**: 깔끔한 올백 또는 포니테일
- **배경**: 회의실 또는 책상 (노트북 보이게)

**예시:** "회의 자료를 보며 자신감 있게 발표하는 모습. 귀걸이가 자연스럽게 빛나는 각도"

#### 2-2. 캐주얼룩 (카페 데이트)
**촬영 가이드:**
- **의상**: 베이지 니트 + 청바지 (편안한 데일리)
- **각도**: 정면 클로즈업 (얼굴 + 귀걸이)
- **표정**: 자연스러운 웃음
- **배경**: 카페 또는 야외 (자연광)

**예시:** "커피를 마시며 친구와 대화하는 자연스러운 순간"

#### 2-3. 이브닝룩 (저녁 약속)
**촬영 가이드:**
- **의상**: 블랙 드레스 또는 슬립 원피스
- **각도**: 후면 측면 (목선 + 귀걸이 + 어깨)
- **헤어**: 뒤로 넘긴 스타일 (귀걸이 강조)
- **배경**: 어두운 톤 (귀걸이 반짝임 대비)

**예시:** "레스토랑에서 고개를 돌리는 순간, 귀걸이가 조명에 반짝이는 컷"

**목적:**
- 7단계 섹션7 "오피스룩부터 캐주얼까지" 시각화
- 3단계 긍정 키워드2위 "다양한 스타일 매치" 증명
- 페르소나 "김세련"의 하루 여정 표현

**제디터 활용:**
- 3장을 나란히 배치 (비포/애프터 느낌)
- 각 이미지에 라벨: "Office / Casual / Evening"

### 📷 **이미지 3: 디테일/신뢰컷 - "실버925 + 무게 비교"**

**촬영 가이드:**
- **구도**: 테이블 위에 귀걸이 + 저울 (5.2g 표시)
- **조명**: 위에서 45도 하향 (디테일 선명)
- **배경**: 화이트 또는 대리석 질감
- **추가 요소**: "925" 각인 클로즈업 컷 추가

**예시 1 (무게 증명):**
"주얼리 저울 위에 귀걸이 한 쌍을 올린 모습. 디지털 숫자 '5.2g' 명확히 보이게"

**예시 2 (소재 증명):**
"귀걸이 안쪽 '925' 각인을 매크로 렌즈로 클로즈업. 실버 광택 강조"

**목적:**
- 7단계 섹션3 "존재감은 크게, 부담은 5.2g" 증명
- 7단계 섹션4 "변색 걱정 없는 투자" 신뢰 구축
- 6단계 차별점2 "무게감 해소" 객관적 데이터 제시

**제디터 활용:**
- 2개 이미지를 좌우 배치
- 왼쪽: 무게 증명 / 오른쪽: 소재 증명
- 텍스트 오버레이: "5.2g의 놀라운 가벼움" + "92.5% 순은 함량"

## 📝 빠른 촬영 팁

### ✅ **지금 당장 촬영 가능 (15분 내 완료)**

**필요한 것:**
- 스마트폰 (인물모드 또는 프로모드)
- 자연광이 들어오는 창가
- 화이트/베이지 배경 (벽 또는 종이)
- 모델 1명 (본인 또는 지인)

**촬영 순서:**
1. **이미지 1 (원터치 클릭)** - 5분  
   → 거울 앞에서 귀걸이 착용하는 손 클로즈업  
   → 연속 촬영 모드로 10장 찍고 베스트컷 선택

2. **이미지 2 (착용컷 3장)** - 10분  
   → 의상만 바꿔가며 측면/정면 각도로 각 3장씩  
   → 자연스러운 표정 (웃거나 고개 돌리는 순간)

3. **이미지 3 (디테일)** - 5분  
   → 테이블 위에 귀걸이 + 저울 (또는 동전 비교)  
   → 위에서 내려찍기, 플래시 켜기

**조명 팁:**
- 창가에서 90도 각도로 서기 (측면 자연광)
- 오전 10시~오후 2시 사이 촬영 (가장 밝음)
- 흐린 날씨가 오히려 좋음 (부드러운 그림자)

**각도 팁:**
- 귀 클로즈업: 45도 측면 (귀 + 목선 보이게)
- 전신 착용컷: 허리 위 상반신만 (귀걸이 강조)
- 디테일: 진짜 위에서 내려찍기 (그림자 최소화)

**예상 소요 시간:** 총 20분

---

### 🎨 **나중에 보완 가능 (전문 촬영 권장)**

**전문 촬영이 필요한 이미지:**
- 추가 이미지 1 (착용 가이드 인포그래픽) → 일러스트레이터 필요
- 추가 이미지 4 (패키지 컷) → 조명 장비 필요
- 추가 이미지 5 (페르소나 라이프스타일) → 스튜디오 촬영 권장

**제디터 AI로 대체 가능한 부분:**
- 배경 제거 및 교체 (화이트/베이지 톤으로 통일)
- 밝기/대비 자동 보정
- 텍스트 오버레이 (메인 카피, 서브 카피)
- 템플릿 기반 레이아웃 자동 생성
- 리뷰 스크린샷 → 타이포그래피 디자인으로 변환

## 🚀 제디터 입력 시 우선순위

### **1단계: 최소 입력 (지금 바로 시작)**
→ PART 1 텍스트 전체 복사  
→ 이미지 1~3 (필수 3장)만 업로드  
→ 제디터 AI 자동 생성 클릭

**예상 결과:** 기본 상세페이지 완성 (전환율 60% 수준)

---

### **2단계: 품질 향상 (1-2일 내)**
→ 추가 이미지 1~3 (선택 이미지) 보완  
→ 제디터에서 섹션 순서 조정 (7단계 시나리오 순서대로)  
→ 리뷰 텍스트 추가 (3단계 긍정 키워드 인용)

**예상 결과:** 프리미엄 상세페이지 (전환율 80% 수준)

---

### **3단계: 최적화 (1주일 내)**
→ A/B 테스트 진행 (이미지 순서 변경)  
→ 고객 리뷰 실제 업로드  
→ 동영상 추가 (원터치 착용 과정 5초 영상)

**예상 결과:** 최적화 완료 (전환율 90%+ 목표)
